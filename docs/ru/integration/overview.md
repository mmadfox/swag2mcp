# Любой MCP-клиент

swag2mcp — это **MCP-сервер** (Model Context Protocol). Это значит, что он работает с **любым MCP-клиентом** — не только с теми, что перечислены в этом разделе. Если ваш редактор, IDE или агент поддерживает протокол MCP, вы можете подключить к нему swag2mcp.

## Универсальный паттерн

Каждый MCP-клиент использует одинаковую базовую настройку. Добавьте swag2mcp как MCP-сервер с:

- **Команда:** `swag2mcp`
- **Аргументы:** `mcp` (плюс опциональный путь воркспейса: `mcp /path/to/workspace`)

```json
{
  "mcpServers": {
    "swag2mcp": {
      "command": "swag2mcp",
      "args": ["mcp", "/path/to/workspace"]
    }
  }
}
```

Точное расположение и формат файла конфигурации (JSON, TOML, настройки GUI) различаются от клиента к клиенту — **посмотрите документацию вашего клиента по MCP**, куда его поместить.

## Транспорты

- **stdio** — работает везде; большинство MCP-клиентов его поддерживают
- **HTTP (SSE / Streamable HTTP)** — поддерживается клиентами с опцией HTTP-транспорта

См. справку по команде [`mcp`](/ru/cli/mcp) для флагов транспорта.

> Если вашего клиента нет в списке, это **не** значит, что он не поддерживается. Пока он говорит на протоколе MCP, используйте универсальный паттерн выше и следуйте мануалу вашего клиента по расположению конфига.
